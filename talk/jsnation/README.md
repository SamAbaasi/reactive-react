# Signals From Scratch — JSNation US 2026

The code built on stage, one step per file. Each step is complete on its own.

| File | Step |
|---|---|
| `01-signal.mjs` | A signal writes down who called it |
| `02-forget.mjs` | Same-value bailout, dependency cleanup, nested callers |
| `03-batch.mjs` | Scheduling, `batch`, `computed` |
| `04-dom.mjs` | `h()`: effects pointed at the DOM |
| `demo-1-2.mjs` | `node demo-1-2.mjs 1` or `2` |
| `demo-3.mjs` | `node demo-3.mjs` |
| `counter.mjs`, `index.html` | `python3 -m http.server 5220`, then open `localhost:5220` |

No dependencies and no build step: Node 18+ for the terminal demos, any modern browser for the counter.
